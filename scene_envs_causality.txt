Kausalitäts-Übersicht (Sperren/Locks) pro Szene
Sperrregel: "gesperrt solange X == s" bedeutet, dass das Objekt vom Agenten
nicht bewegt/gedrückt werden kann, bis der Zustand von X nicht mehr s ist.
Buttons rotieren die Zustände (2-stufig: 0->1->0; 3-stufig: 0->1->2->0).

SceneEnv1
- btn0 (3-stufig): immer drückbar.
- faucet0: gesperrt solange button0 == 1.
- faucet1: gesperrt solange faucet0 == 1.3 UND button0 == 2.
- cube0: frei (keine Sperren); kann auf shelf0 abgelegt werden (Container).
- shelf0: passiver Container, keine Interaktion.

SceneEnv2
- btn0 (3-stufig): immer drückbar.
- btn1: gesperrt solange button0 == 2.
- faucet0: gesperrt solange button0 == 0 UND button1 == 1.
- peg0: frei (keine Sperren).
- lid0: frei (keine Sperren); kann auf/in box0 abgelegt werden (Container).
- box0: passiver Container, keine Interaktion (Deckel blockiert Zugang).

SceneEnv3
- btn0: gesperrt solange button1 == 1.
- btn1: immer drückbar.
- btn2: gesperrt solange button0 == 0.
- drawer0: gesperrt solange button0 == 1.
- cube0: frei (keine Sperren); kann auf shelf0 oder in drawer0 abgelegt
  werden (Container).
- shelf0: passiver Container, keine Interaktion.

SceneEnv4
- Keine Buttons, keine Sperren; alles ist frei beweglich.
- cube0: kann auf shelf0 oder in box0 abgelegt werden (Container).
- lid0: kann auf/in box0 abgelegt werden (Container).
- peg0: frei (keine Sperren).
- box0/shelf0: passive Container, keine Interaktion.

SceneEnv5
- btn0: gesperrt solange button1 == 2.
- btn1 (3-stufig): immer drückbar.
- btn2: gesperrt solange button0 == 0.
- drawer0: gesperrt solange button0 == 0 UND button1 == 2.
- slider0: frei (keine Sperren).
- faucet0: frei (keine Sperren).
